# 指板図のモーダルスケール拡充(フリジアン/リディアン/ロクリアン) — 要求仕様

## 背景と目的

[003-fretboard-scale-marking](../003-fretboard-scale-marking/spec.md) で指板図のスケール自動マーキングが実装され、直近のコミットでドリアン・ミクソリディアンについては特徴音(そのモードらしさを決定づける音)を紫色で強調表示できるようになった。しかしモーダルスケールは 7 種のうちドリアン・ミクソリディアンの 2 種しか選択肢がなく、フリジアン・リディアン・ロクリアンが指板図で選べない。ペルソナ(vision.md: アドリブに必要な指板の理解が頭に入らない)がモード奏法を学ぶ際、フリジアンの b2 やリディアンの #4 といった「そのモードを特徴づける音」を指板上で確認できないのは理論レンズとして片手落ちである。

## vision との対応

- **対応する柱**: vision 柱 2「理論レンズ」(指板図にスケール構成音を重ねる) / improvement-policy 柱 C-3「`ScaleType` に phrygian / lydian / locrian を追加してモードを網羅」(ロードマップ順 3)
- **非ゴール確認**: DAW 化・浄書・共有プラットフォーム・モバイル編集のいずれにも抵触しない。既存の自動マーキング・特徴音強調の仕組みを対応スケール分だけ拡張するもので、新しい表示モデルは導入しない

## スコープ

- `ScaleType` にフリジアン(`phrygian`)・リディアン(`lydian`)・ロクリアン(`locrian`)を追加し、指板図ブロックのスケール選択肢として選べるようにする
- 追加した 3 モードの構成音を、既存のドリアン・ミクソリディアンと同じ自動マーキングの仕組み(003 spec)に乗せる
- 追加した 3 モードの特徴音を、既存のドリアン・ミクソリディアンと同じ紫色の強調表示で示す
  - フリジアン: 短 2 度(♭2)
  - リディアン: 増 4 度(#4)
  - ロクリアン: 短 2 度(♭2)と減 5 度(♭5)の **両方**(該当する構成音位置がそれぞれ強調される)
- スケール選択 UI(学習段階別グルーピング)に 3 モードを日本語慣用名(フリジアン/リディアン/ロクリアン)で追加する。既存のドリアン・ミクソリディアンと同じグループ(「慣れてきたら」相当)に置き、グループ内ではモード系(ドリアン/フリジアン/リディアン/ミクソリディアン/ロクリアン)を隣接させて並べ、ハーモニックマイナー/メロディックマイナーと交互にならないようにする(「モードの仲間」というまとまりを視認しやすくするため)
- 自動マーカーのホバー表示(既存の音名・度数ツールチップ)に、その位置が特徴音であるときは「特徴音」であることを示す文言を追加する。ロクリアンの 2 つの特徴音(♭2・♭5)がそれぞれ独立した音であることが、ホバーにより判別できるようにする

## 非スコープ

- Ionian・Aeolian を独立したモードとして `ScaleType` に追加すること — 既存の `major` / `naturalMinor` と構成音が同一であり、別名を増やすと選択肢が重複するだけで学習上の利点がない。将来「モードとして意識させたい」要望が出たら別途判断する
- 異名同音の綴りをキー(調号)から自動導出すること(例: 特定のルートでは #4 ではなく ♭5 と綴るべきといった判定) — improvement-policy 柱 C-3 に含まれるが、既存のドリアン・ミクソリディアンの表示も現状この綴り分けをしていないため、本 spec では既存挙動に合わせて据え置く。綴り精度の改善は独立した spec で扱う
- TAB ブロックへの適用(音名・度数オーバーレイへのモード対応) — improvement-policy 順番 4 の別 spec
- モードごとの詳細な理論解説・凡例(「フリジアンとはどういう響きか」等のヘルプ) — improvement-policy 柱 A(ヘルプ整備)の spec で扱う
- スケール選択肢のラベルに特徴音を併記すること(例: 「フリジアン(♭2)」)— `ROOT_OPTIONS` の異名同音併記(`C# / D♭`)と似た着想だが、本 spec ではホバーツールチップでの案内に留め、選択肢ラベルは変更しない。選択前から特徴音を知らせる価値と選択肢の煩雑化を天秤にかけた結果であり、要望が出たら別途判断する

## ユーザーストーリー

1. フラメンコ/メタル調のフレーズを弾くとき、フリジアンの指板上の形と、その響きを決定づける♭2 の位置を確認しながら覚えたい。なぜならペンタトニックと違い、フリジアンは形だけ覚えても♭2 の使いどころが分からないと「らしさ」が出せないから
2. リディアンで即興するとき、#4 がどこにあるかを常に指板上で意識したい。なぜならリディアンをただのメジャースケールと勘違いして弾くと #4 を避けてしまい、リディアンらしさが失われるから
3. ロクリアンは 2 つの特徴音(♭2・♭5)があると知りたい。なぜなら 1 つだけ覚えると「不安定な響きの理由」を理論的に理解できないから

## 受け入れ基準(EARS 形式)

機能:

- **AC-1**: WHEN 指板図ブロックのスケール選択肢を開く THEN フリジアン・リディアン・ロクリアンが日本語慣用名で選択肢に表示される(既存のドリアン・ミクソリディアンと同じグループ内、モード系が隣接する並び順で)
- **AC-2**: WHEN スケールにフリジアンを選択する THEN 表示フレット範囲内のフリジアンの全構成音が自動マーキングされ、そのうち♭2 にあたる位置が紫色の強調表示になる
- **AC-3**: WHEN スケールにリディアンを選択する THEN 表示フレット範囲内のリディアンの全構成音が自動マーキングされ、そのうち増4度(半音6つ分)にあたる位置が紫色の強調表示になる。ラベル表示が「度数」のときこの位置は既存の `DEGREE_NAMES` に従い `♭5` と表示される(非スコープのとおり `#4` 表記への綴り分けは本 spec では行わない)
- **AC-4**: WHEN スケールにロクリアンを選択する THEN 表示フレット範囲内のロクリアンの全構成音が自動マーキングされ、♭2 と♭5 にあたる位置の **両方** が紫色の強調表示になる(どちらか一方のみにはならない)
- **AC-5**: WHEN フリジアン・リディアン・ロクリアン・ドリアン・ミクソリディアンを除く残り 7 種(メジャー・ナチュラルマイナー・ハーモニックマイナー・メロディックマイナー・メジャーペンタトニック・マイナーペンタトニック・ブルース)を選択する THEN 特徴音の強調表示は行われない(この 7 種には元々強調表示の仕組みが無い)
- **AC-6**(既存モードの回帰なし): WHEN 本 spec 実装後にドリアンまたはミクソリディアンを選択する THEN 従来どおりそれぞれ 1 箇所(ドリアン: 長6度、ミクソリディアン: ♭7)が紫色で強調表示される(3 モード追加によってデータ構造を変更しても既存挙動を壊さない)

手動マーカー・ラベル表示との両立:

- **AC-7**(ラベル表示との両立): WHEN フリジアン/リディアン/ロクリアンを選択し AND ラベル表示を「度数」または「音名」にする THEN 特徴音の位置にも他の構成音と同様に度数・音名ラベルが表示され、強調表示(紫)と共存する

初見の理解可能性:

- **AC-8**: WHEN 自動マーカーのうち特徴音にあたる位置をホバーする THEN 音名・度数に加えて、その音が(そのモードを特徴づける)特徴音であることを示す文言がツールチップに表示される。AND WHEN 特徴音を含むスケール(ドリアン/フリジアン/リディアン/ミクソリディアン/ロクリアン)を選択している間 THEN ホバーせずとも「紫の点は特徴音」であることが分かる短い案内文がブロック上に常時表示される(既存の keyContext 未設定時のヒント表示と同様の扱い。ホバーという操作自体に気づけない初見のユーザーでも紫の意味に到達できるようにするため)
- **AC-9**: WHEN ロクリアンを選択して 2 つの特徴音(♭2・♭5)が表示されている THEN それぞれをホバーすると独立した音名・度数が表示され、2 箇所(または複数フレット・複数弦にわたる該当位置すべて)の強調表示が表示不具合ではなく仕様であると判別できる
- **AC-10**: WHEN ラベル表示モードが「点のみ」(ラベル非表示)で特徴音が表示されている THEN 色による強調表示に加えて、ホバーにより当該位置が特徴音であることを確認できる(色のみに依存する情報にならない)

エッジケース・永続化:

- **AC-11**(永続化): WHEN フリジアン/リディアン/ロクリアンを選択したブロックを保存して再読込(IndexedDB / JSON エクスポート→インポート)する THEN 選択したスケールと強調表示が復元される。旧データ(この 3 モードを使っていないデータ)も従来どおり開ける
- **AC-12**(左右反転表示との併用): WHEN [002-fretboard-lefty-mirror](../002-fretboard-lefty-mirror/spec.md) の左利きミラー表示中に フリジアン/リディアン/ロクリアン を選択する THEN 特徴音の強調表示も鏡像位置に正しく表示される

## 関連 spec との相互作用

- [003-fretboard-scale-marking](../003-fretboard-scale-marking/spec.md): 自動マーキング・ラベル表示モードの土台。本 spec はその対応スケールを拡張するのみで、マーキングの仕組み自体は変更しない
- 直近コミット(2a607a8, 指板図でモーダルスケールの特徴音を紫で強調表示する)で実装されたドリアン・ミクソリディアンの特徴音強調の仕組みを 3 モード分拡張する

## 要確認

なし。以下はユーザーに確認済み:

1. **進め方**: `/specify` で spec を切ってから `/spec-plan` → `/spec-implement` に進む(確認済み)
2. **ロクリアンの特徴音**: ♭2 と♭5 の両方を紫で強調表示する(確認済み。片方のみ(♭5 のみ)という案もあったが、不採用)

`spec-reviewer` / `ux-designer` によるレビューを反映済み:
- AC-5 の文言矛盾(既存 9 種のうちドリアン・ミクソリディアンを回帰させてよいと読める曖昧さ)を修正し、AC-6 として既存モードの回帰なしを独立検証項目にした
- AC-3 に、リディアンの増4度が度数ラベル上は `♭5` と表示されること(既存 `DEGREE_NAMES` の綴り仕様を維持)を明記した
- 「紫色が何を意味するか」を伝える手がかりが無いという指摘を受け、AC-8〜10(ツールチップへの「特徴音」文言追加、ロクリアンの 2 特徴音の判別可能性、ラベル非表示時の色のみ依存の回避)を追加した
- スケール選択 UI のグループ内並び順(モード系を隣接させる)をスコープに明記した
- design.md レビューで ux-designer から「ホバーという操作自体に初見のユーザーが気づけない」という should 指摘を受け、AC-8 に常時表示の短い案内文(既存の keyContext 未設定時ヒントと同様の扱い)を追加した
